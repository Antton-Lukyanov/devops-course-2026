# Git vs SVN

1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?
В Git ветка — это просто указатель на коммит (файл размером 41 байт). Создание ветки не копирует файлы и не требует обращений к серверу. В SVN ветка — это копия директории на сервере: приходится дублировать структуру, что занимает место и время.

2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет. SVN — централизованная система: коммит уходит на сервер, без соединения с ним зафиксировать изменения невозможно. В Git коммиты делаются локально, а связь с сервером нужна только для push/pull.

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
- Legacy-проекты, где миграция на Git дороже поддержки SVN.
- Жёсткий контроль доступа к отдельным директориям (в SVN это встроено).
- Работа с очень большими бинарными файлами без нужды в распределённости.
- Госсектор и банки с устаревшей инфраструктурой и строгими регламентами.
