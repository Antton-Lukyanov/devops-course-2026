# Мой пет-проект

Идея: телеграм-бот для учёта личных расходов — пользователь пишет боту сумму и категорию, бот сохраняет запись и по команде `/stats` показывает, сколько потрачено за месяц по каждой категории.

Стек: Python (aiogram), SQLite для хранения записей, Docker для запуска.

Цель: научиться писать телеграм-ботов, работать с базой данных и упаковывать приложение в Docker-контейнер. В результате я хочу получить — работающий бот, задеплоенный на сервер.

Сроки реализации
| Этап | Что делаем | Срок |
|------|------------|------|
| 1 | Регистрация бота, базовая команда `/start` | 1 неделя |
| 2 | Добавление записей о расходах (сумма + категория) | 1 неделя |
| 3 | Команда `/stats` со статистикой по категориям | 1 неделя |
| 4 | Упаковка в Docker и запуск локально | 1 неделя |
