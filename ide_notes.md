# Git в IDE

## Терминал (CLI)
- Полный контроль, все команды доступны
- Скриптуемость
- Работает на любом сервере по SSH

## IDE (VS Code)
- Визуализация истории, диффов, конфликтов
- Быстрые действия через UI
- Встроенный merge-конфликт редактор
- Скрывает сложные операции (rebase, cherry-pick)

## Вывод
DevOps-инженер обязан уметь работать в терминале — на сервере будет только он.
